这不是一家产品公司。板上已经写好「做什么、给多少钱」。你只接和驾驶舱同构的活（只读 CLI、监控、文档+小工具），做完验收拿钱。用来养 hlsentry / oddsradar / chaintail，不当身份。

## 状态

空仓库 + 规格。没有自建赏金市场。

## 明确不做

- 托管资金、代下单、任何会动别人钱的题
- 同时接 3 单
- 只靠赏金当长期生意
- 没有能跑的 demo 就去海投 grant
