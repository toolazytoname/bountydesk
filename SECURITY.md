# Security

bountydesk tracks **your** applications and notes. It is not a custodian.

## Rules

- Never paste private keys, seed phrases, or exchange API secrets into issue templates, CSVs, or proposal drafts in this repo.
- Grant / Earn payout addresses are public receive addresses only. Document them off-git if you must keep a personal map.
- Do not test other people’s production systems without written permission. Bounty platforms ban mainnet “testing” that touches live funds.
- If a task requires signing or holding user assets, refuse it. This desk only takes read-only or docs/tooling work.

## Reporting

This repo should contain no secrets. If one lands in git history, rotate it and treat the commit as compromised.
