# bountydesk — 项目说明

> 推荐顺序第 5。现金流插件，不当主业。  
> 来源：`web3_explore/doc/next/WEB3-DIRECTIONS.md`

## 概述

基金会或项目在板上贴任务：「做这个 CLI / 修这个文档 / 接这个 SDK，给 $X」。你交仓库，他们验收打款。是接单，不是做自己的产品。

本仓库是**你的工作台**：记选了哪单、交到哪、打没打款。不自建赏金市场。

## 你自己怎么用

缺现金时打开这里，挑一单和 1～3 同构的活。做完记一笔。不在这里发明新协议。

## 一开始

1. 维护 `docs/inbox.md`：正在看的 1～3 个任务（链接、金额、截止日期、和驾驶舱是否同构）
2. 维护 `docs/ledger.md`：已提交 / 已打款
3. 提案只写一页：痛点、做什么、明确不做、已能跑什么、三个里程碑

## 后面

重复劳动收进 hlsentry / oddsradar / chaintail。赏金养作品，作品不是为了堆赏金。

## 上限

熟练之后可以接近一份远程零工收入。天花板是自由职业，不是产品公司。单子会断，平台会变。

## 挣钱

全菜单里最早可能进账的。一单常见几百到几千美元。Tether 一类按任务结的资助，公开口径大约 $1.5k–4k，申请前核对是否仍开放。

## 获客

填表。不愿社交时最干净的收钱通道。

## 入口（动手前再点开核对，规则会变）

- Superteam Earn：https://earn.superteam.fun/  
  微额常看地区，大陆资格别默认有
- Solana grants：https://solana.org/grants-funding
- Gitcoin：https://www.gitcoin.co/
- Base 追溯资助（已上线的东西）：见 Base docs / Builder Grants
- Tether developer grants：申请前核对开放状态

## 只接这类题

- 只读监控、本地 CLI、文档、示例集成
- 做错了顶多报错，不会让别人亏钱

## 不接

- 智能合约审计当第一单、交易 bot、托管钱包、代客执行
